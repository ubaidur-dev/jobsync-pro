# JobSync Pro — Your Next Move Starts Here
Finding a job can be a stressful and slow process, so I built JobSync Pro to make it fast, clean, and actually useful. This isn't just a basic website, it's a professional tool designed to help people find great opportunities without any extra noise.

### Project Goals
* **Live Job Discovery:** I included 12+ real-world job categories like AI Engineering, Blockchain, and Marketing so anyone can find something relevant.
* **Detailed Job Overviews:** When you click a job, you get the full story—company details, what they need from you, and clear salary info. No more guessing.
* **Smart Save Feature:** I added a bookmarking system that saves your favorite jobs in the browser, so they are still there even if you refresh the page.
* **Employer Dashboard:** I built a professional form where companies can easily post new jobs with all the necessary details like description and requirements.

### Tech Stack
* **React.js:** Used this for all the logic and building reusable parts so the website stays fast and smooth.
* **Tailwind CSS:** All the styling is done with Tailwind to make sure the site looks perfect on both mobile phones and laptops.
* **Lucide Icons:** I picked clean, modern icons to give the interface a high-quality **"world-class"** feel.
* **Vite:** I used Vite for the setup because it’s much faster for development compared to older tools.

### Folders Structure
* **src/hooks:** This is where the "brain" of the app lives, handling the job data and the saving logic.
* **src/pages:** Dedicated pages for the Home screen, the Bookmarks list, and the new Job Details view.
* **src/components:** Reusable parts like the Navbar, the Search bar, and the Job cards to keep the code clean.
* **src/assets:** Where I keep the global styles and professional font settings.

### How to Run
* Clone or **download this repository** to your computer.
* Open your terminal and type **npm install** to get all the needed files.
* Type **npm run dev** to start the project and see it **live in your browser**.
